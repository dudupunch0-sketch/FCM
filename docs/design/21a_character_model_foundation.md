# 캐릭터 모델 골조 — 성인 스포츠 애니메이션 방향

## 목표

미형의 기준을 단순한 미화 필터가 아니라 공통 비례와 실루엣으로 관리한다.
이번 기준은 성인 남성 복서다. 추후 다른 성별·체형에는 별도의 비례 프리셋을 추가하며 현재 범위를 전체 선수의 유일한 미적 기준으로 고정하지 않는다.

| 영역 | 공통 방향 | 선수별 차이 |
|---|---|---|
| 얼굴 | 턱·광대·이마가 이어지는 하나의 표면, 정돈된 턱선 | 턱/광대 폭과 턱끝 |
| 눈 | 얕은 눈 주변, 가는 윗눈꺼풀, 읽히는 눈썹 | 눈 간격·높이·폭·눈썹 기울기 |
| 코·입 | 얼굴 표면에서 이어지는 코, 절제된 입선 | 코 돌출과 입 폭 |
| 헤어 | 작은 디테일보다 앞머리와 정수리 실루엣 | 넘긴 머리 / 짧은 머리, 볼륨·색 |
| 몸통 | 넓은 어깨에서 허리로 이어지는 매끈한 형태 | 어깨·허리 폭, 가슴 깊이 |
| 팔다리 | 관절 길이를 유지하는 공통 애니메이션 골격 | 제한된 범위의 근육 굵기 |

## 구현 계층

- `character-profile.js`: 외형만 제어하는 공통 프로필과 허용 범위. 전투 능력치와 분리한다.
- `character-head.js`: 연속적인 얼굴 메시와 눈·헤어 구성. 얼굴과 몸통의 겹친 구체를 줄인다.
- `fighter-model.js`: 외형 프로필을 읽어 기존 관절 구조에 연결한다.
- `motion.js`: 기존 동작을 재사용한다. 외형 차이를 경기 성능으로 환산하지 않는다.

현재 기본형은 비교적 가는 턱선과 넘긴 머리, 상대형은 넓은 턱과 짧은 머리다. 색상만 바꾼 복제를 넘어 실루엣 차이를 만든다.
프로필은 생성 시 범위를 검증하고 변경 불가능하게 유지한다. 셰이더를 바꾸더라도 비례와 랜드마크를 재사용할 수 있는 구조다.

## 이번 변경과 이후 작업

이번에는 미형 캐릭터를 만들기 위한 공통 조절 기준, 얼굴 표면, 몸통 정리와 관절 연결까지 구현한다.
카툰 명암·외곽선 셰이더, 전투 속도 변경, UI 재설계는 포함하지 않는다.

다음 아트 검수에서는 정면·측면·사선에서 턱선, 코 돌출, 헤어 경계, 눈의 가독성을 먼저 확인한다.
그 뒤 가드·최대 타격·위빙 자세에서 어깨와 목의 겹침을 확인하고 카툰 명암을 적용한다.
최종 고품질 캐릭터에는 조형 툴의 수작업 보정, 통합된 변형 메시와 스킨 웨이트가 추가로 필요할 수 있다. 이번 골조만으로 완성된 상용 캐릭터 품질을 주장하지 않는다.

## 검증

기존 모션/전투 테스트와 외형 프로필 검증을 실행한다. 잘못된 비례 거부, 프로필 불변성, 얼굴 좌표 및 동작 중 관절 좌표의 유한성을 확인한다.
실제 렌더 화면을 이용한 미적 검수는 아직 수행하지 않았다.
