# 재사용 모션 작업실

2026-09-13. 사용자가 반복 이미지 생성 비용을 줄이기 위해 관절·동작 템플릿 기반 제작 도구 구현을 승인했다. 이전 `24_2d_animation_handoff.md`의 훅 재생성 반복은 중단했다.

## 실행

WSL에서 `npm start`, 브라우저에서 `http://localhost:8000/motion-workbench.html`.

훅·상단 가드·위빙 선택, 공격 손 선택, 시간·접촉점·상체 이동·위빙 깊이 조절. 재생/일시정지, 진행 슬라이더, 관절 표시, 원본 겹쳐 보기 제공. 편집·재생·내보내기는 브라우저 계산만 사용하며 AI/API 호출이 없다. 정지 상태에는 반복 렌더 루프도 없다.

`동작 JSON 저장`으로 파일을 다운로드한다. `동작 파일 불러오기`에 내용을 붙여 넣고 적용하면 복원된다. `12프레임 PNG`는 투명 4열×3행 이미지를 만들며, `내보내기 정보`에 각 사각형과 샘플 시간이 표시된다. 첫/마지막 자세와 접촉 시점을 포함한다. 프레임 시간은 등간격을 가정하지 말고 JSON을 따른다.

## 구조와 수정 범위

- `dist/rig-motion.js`: 브라우저와 분리된 순수 함수. `validateClip`, `sampleClip`, `inspectClip`, `bakeClip`. 앞손/뒷손 식별 고정. 팔 두 뼈 길이를 보존하는 IK. 도달하지 못하는 목표는 팔을 늘리지 않고 오차로 표시.
- `dist/rig-painter.js`: 기존 사용자 원화의 얼굴·팔·장갑·하체를 런타임에 마스킹. 원본에 가려진 몸통은 임시 색면과 선으로 보완. 새로운 AI 이미지를 생성하지 않는다.
- `dist/motion-workbench.html`, `.js`: 조절·검수·저장 인터페이스. 클립 파일에 실행 코드나 외부 URL을 넣을 수 없다.
- `dist/assets/cel-boxer/head-source.png`: 사용자가 준 초기 가드 원본의 동일 바이트 복사. 올린 장갑에 가리지 않은 턱을 사용하기 위한 얼굴 소스. 개발용 선수 사진/닌텐도 레퍼런스는 포함하지 않는다.

가벼운 모델은 스키마 범위 안에서 JSON 숫자만 수정하면 된다. 파일을 직접 조절할 때는 LLM이 필요 없다. 새 동작 문법, 가려진 부위, 새로운 시점의 그림까지 자동 해결하는 범용 엔진은 아니다.

## 검수 및 한계

- 자동 검증: 모든 기존 테스트와 새 IK/손 식별/복귀/시간 독립/입력 검증/접촉 포함 내보내기 테스트.
- 브라우저: 훅 자동 재생 진행 및 종료, JSON 재적용, PNG 생성과 실제 Downloads 파일 확인. 다운로드 이벤트 도구는 타임아웃했으나 실제 PNG 파일은 생성되어 직접 열어 확인했다.
- 모바일 390px 화면에서 위빙 선택·중심 자세 조작, 가로 넘침 없음 확인. 실물 휴대폰 접속 검증은 아니다.
- 원화를 분리한 어깨/팔 경계와 임시 몸통은 최종 일러스트 품질이 아니다. 훅은 짧은 팔 이동의 제작 예제이며 회전·힘 전달의 최종 복싱 모션 승인이 아니다. 위빙 하체는 단순 이미지 변형이므로 다리 뼈 길이 보존을 주장하지 않는다.
- 게임 런타임에는 아직 적용하지 않는다. 기존 `?art=cel`과 전투 판정은 그대로. 제작 도구의 접촉 마커는 시각 기준이며 상대의 게임 히트박스가 아니다.
- 원화, 기본 포즈, 장갑 접촉점은 현재 캐릭터/시점에 맞춘 데이터다. 다른 캐릭터는 마스크·관절·랜드마크 조정이 필요하다.

## PC 종료와 모바일

ChatGPT Work의 Cloud 옵션이 제공되는 계정은 PC 종료 후에도 클라우드 작업을 이어갈 수 있다. 로컬 PC의 파일·Blender·localhost는 PC 종료 후 사용할 수 없다. Work를 쓰는 것만으로 로컬 작업이 클라우드로 복사되지는 않는다.

`python3 tools/animation/pack_motion_workbench.py`는 `artifacts/motion-workbench.zip`을 만든다. 외부 의존성 없는 HTML/JS/원화 묶음이다. 정적 HTTP 호스팅에 올리면 모바일 브라우저에서 조절할 수 있다. 현재 원격 업로드·호스팅은 하지 않았다. ZIP은 재생성 가능하며 Git에는 소스와 패키징 스크립트만 보관한다.

공식 근거: https://learn.chatgpt.com/docs/get-started-with-work (`Choose local or cloud work`).
