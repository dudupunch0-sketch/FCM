# FCM 2D 캐릭터 제작 방향

작성: 2026-09-12.

최신 구현 상태와 다음 작업(2026-09-13): [2D 애니메이션 인계](24_2d_animation_handoff.md). 아래 제작 상태는 최초 두 자세 시안의 이력이다.

## 확정된 범위

사용자 결정: “방향을 정하자. 2d로 하는게 낫겠어.” 캐릭터와 전투 화면을 2D 방향으로 진행한다. 스타일리시한 외형, 빠른 선택 반응, 선명한 타격을 목표로 한다.

기존 Rook 3D 시안은 사용자가 외형에 불만을 표시했으므로 최종 캐릭터로 채택하지 않는다. Blender 기반 모션 스터디는 중단한 실험 자료다. 기존 도트 스프라이트는 새 자산이 검토될 때까지 실행 가능한 임시 표현으로 유지한다.

2D 선택이 특정 화풍·얼굴·복장까지 승인한 것은 아니다. 아래 내용은 다음 시안을 위한 제작 제안이다.

## 제안하는 시각 방향

- **고해상도 손그림 셀 채색.** 명확한 외곽선과 2~3단계 명암으로 얼굴, 장갑, 팔의 겹침을 읽기 쉽게 한다. 작은 화면에서도 형태가 유지되도록 잔근육과 질감보다 큰 색면을 우선한다.
- **날렵한 성인 복서.** 자연스럽게 이어지는 어깨·팔·손목, 탄탄한 체형, 선명한 눈과 턱선, 덩어리가 정돈된 헤어를 제안한다. 실제 얼굴·체형·복장·색은 첫 원화에서 비교한다.
- **측면 중심의 전신 구도.** 얼굴이 조금 보이는 각도로 가드 자세를 잡고 두 선수의 발과 장갑이 화면 안에 들어오게 한다. 배경 대비를 낮추고 선수와 접촉점을 강조한다.
- **직접 그린 핵심 자세와 프레임 애니메이션.** 준비 → 체중 이동 → 접촉 → 회수를 분리한다. 잽·크로스·훅은 어깨 회전과 팔 궤적으로 구별하며, 이동 없는 공격은 지지발이 미끄러지지 않게 한다.
- **짧고 강한 UI 반응.** 어두운 중성 패널과 라임 선택색을 이어가고, 선택 카드는 즉시 배치한다. 긴 카드 비행이나 화면 전환으로 다음 입력을 기다리게 하지 않는다.

외형 참고 기준은 [링크 레퍼런스](../art/reference/link/README.md)와 해당 로컬 이미지다. 눈·턱·헤어의 형태와 셀 명암을 직접 대조한다. 참고 이미지 자체와 그 복장·장비를 게임 배포 자산으로 사용하지 않는다.

## 첫 제작 단위와 확인 기준

1. 효과와 배경을 뺀 전신 가드 원화 한 장을 만든다. 얼굴 확대와 실제 모바일 표시 크기를 함께 확인한다. 멋있는 기본 외형을 확보하기 전에는 전체 동작을 늘리지 않는다.
2. 같은 인물로 잽·크로스·훅·피격의 핵심 자세를 만든다. 접촉 자세만 나란히 놓아도 공격 종류가 구별되어야 한다.
3. 준비·회수 프레임을 보강하고 투명 배경과 일정한 발 기준점으로 아틀라스를 제작한다. 자동 생성 이미지는 원재료이며 프레임 분리·크기·여백·알파를 검증한다.
4. 실제 게임에 넣어 정상 속도와 프레임 단위로 확인한다. 얼굴과 팔다리 비율의 일관성, 지지발, 장갑 접촉점, 콤보 전환, 좁은 화면의 잘림을 확인한다.

전투 엔진의 판정·가드 구간·정보 공개는 그대로 기준으로 삼는다. 동작을 보기 좋게 만들기 위해 판정 시간을 변경하지 않는다. 계획에는 제한 시간을 추가하지 않고, 실행 구간에서 속도감을 만든다. 상세 UI 시간과 타격 효과의 제안은 [22번 문서](22_ui_motion_direction.md)를 따른다.

## 현재 제작 상태

### 사용자 자료 수령 후 갱신

사용자가 가드·스트레이트 캐릭터 그림과 동작 참고 자료 7장을 제공했다. 추가 원화를 요청하지 않고 남은 동작은 개발자가 직접 제작한다. 별도의 새 원화를 선행 조건으로 두지 않는다. 아래 이미지 생성 제한 기록은 최초 시도 당시의 이력이다.

`http://localhost:8000/?art=cel`에서 두 그림을 적용한 전투 시안을 확인할 수 있다. 흰 배경 제외, 발 기준 정렬, 상체 기울기·낮추기, 직선 공격의 두 자세 전환, 접촉 효과를 연결했다. 기본 게임 주소는 전용 동작 그림이 있는 기존 표현을 유지한다.

시안의 한계: 두 선수는 동일 외형을 반전해 사용한다. 잽/크로스는 같은 스트레이트 그림을 공유한다. 훅·바디 훅·오버핸드는 전용 접촉 그림이 없으며 기본 가드를 유지한다. 수비·회피는 상체 변형 수준으로 관절별 프레임 애니메이션이 완성된 것이 아니다. 남은 제작 책임은 개발자에게 있으며, 사용자에게 추가 생성 작업을 되돌리지 않는다.

자세별 자료와 작업 순서: [사용자 제공 복싱 자료](../art/reference/boxing-user/README.md).

### 최초 시도 이력

- UI와 기존 스프라이트의 연출 개선은 로컬 작업으로 존재한다. 새 2D 캐릭터가 구현된 상태는 아니다.
- 첫 2D 가드 원화 생성을 시도했으나 이미지 생성 사용량 제한으로 실패했다. 새 원화 또는 승인된 새 스프라이트는 아직 없다.
- 새 원화 생성이 가능해지면 위 첫 제작 단위부터 진행한다. 추가 도구 설치를 현재 필수 조건으로 삼지 않는다.
