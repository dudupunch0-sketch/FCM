# FCM — 콤보형 턴제 전투와 정보 공개 스킬카드

> 상태: 사용자 승인 방향 반영. 카드 이름과 세부 효과는 콘텐츠 초안이며 수치 밸런스는 미확정.
> 기준: [현재 결정](../spec/current_decisions.md)
> 범위: 전투 명세 변경. 실행 코드나 애니메이션 구현 완료를 의미하지 않는다.

## 확정 방향

- 실시간 대전 대신 콤보를 계획하고 동시 실행하는 턴제 전투를 사용한다.
- 콤보 타임라인은 8칸이며 동작카드는 1~4칸을 점유한다. 칸은 카드 수가 아니라 시간이다.
- 짧은 가드와 긴 가드, 페이크, 스웨이·위빙, 스태미너 관리와 카운터를 지원한다.
- 스킬카드는 상대 행동 일부를 읽는 조건부 능력을 제공할 수 있다.
- 선수 육성, 기술 숙련, 부위별 손상, 전신 HP 없는 피니시, 기존 전투 계산 계층은 유지한다.
- 기존 Skill Card는 선수 특성이고 Action Card는 배운 Technique를 사용하는 조작 단위다. 별개의 무작위 덱 시스템으로 합치지 않는다.

## 콤보 진행

상대 계획 확정 → 관찰 정보 생성 → 플레이어 배치 → 플레이어 확정 → 동시 실행 → 결과/패턴 기록 → 다음 콤보.

상대는 플레이어의 현재 편집 중인 계획을 읽지 않는다. 공개 이후 상대 계획을 다시 생성하지 않는다.
확정 공개는 계획에 대한 보장이다. 실행 중 피격·스태미너 부족 등으로 계획이 실패할 수는 있으며, 그 원인은 로그에 남긴다.
턴과 경기 라운드는 별개다. 라운드 시간에 콤보를 어떻게 대응시킬지는 구현 전 조정 항목이다.

공격에는 준비, 타격 시점, 회수 구간을 정의한다. 가드는 활성 구간, 회피는 회피 구간을 가진다.
점유한 모든 칸에 타격을 반복하지 않는다. 짧은 동작은 같은 칸 내부의 단계로 표현할 수 있다.
선수 속도와 숙련도가 이 타이밍에 미치는 정확한 규칙은 별도 검증한다.

예시 배치: 잽 1칸 + 페이크 1칸 + 위빙 2칸 + 크로스 1칸 + 긴 가드 3칸 = 8칸.
이는 배치 설명용이며 개별 기술의 최종 점유 길이는 아니다.
1칸 가드와 4칸 가드를 포함해 방어 지속 시간별 선택지를 제공한다.

## 방어와 자원 교환

| 동작 | 성공 보상 | 비용과 위험 |
|---|---|---|
| 짧은 가드 | 예상한 타격 순간을 효율적으로 방어 | 타이밍이 틀리면 노출 |
| 긴 가드 | 넓은 시간 구간 방어 | 공격 기회 손실, 비보호 부위와 페이크에 취약 |
| 스웨이·위빙 | 궤도에 맞는 회피 후 짧은 카운터 기회 | 부적절한 회피는 취약한 자세에서 피격 |
| 페이크 | 상대의 방어/회피를 헛쓰게 하고 후속 공격 준비 | 반응하지 않는 상대에게 시간과 스태미너 낭비 |
| 호흡 정리 | 회복 기회 | 상대 압박에 노출 |

가드도 보호 부위와 관통 충격, 팔의 누적 손상, 유지 비용을 가진다.
기본 블록은 공격자가 쓴 공격 비용보다 적은 방어 비용으로 스태미너 교환에서 이득을 보는 방향이다.
상대 스태미너 추가 감소는 기본 블록의 보편 효과로 확정하지 않고 특수 방어 효과 후보로 남긴다.
회피 보상은 상대 회수 구간을 노리는 짧은 카운터 기회다. 영구 보관 가능한 버프로 만들지 않는다.
회피 종류별 상성, 카운터 유효 시간, 피해/비용/회복 공식은 데이터로 조정한다.

## 정보 공개 원칙

- 정보 카드가 없어도 이전 콤보와 관찰한 반복 습관을 확인할 수 있다.
- 정보 카드는 추가적인 확실성 또는 특정 의도 단서를 제공하며 필수 장착이 되지 않도록 검증한다.
- 카드 효과는 공개 대상, 공개 정밀도, 조건, 공개량, 지속 시점으로 구분한다.
- 확정 정보는 실제 잠긴 계획과 일치한다. 추정 정보는 관찰된 징후이며 틀릴 수 있다.
- 정확한 카드 공개로 페이크를 보았다면 페이크라고 표시한다.
- 강공격처럼 보이는 예고는 페이크에 속을 수 있다. UI에서 확정 정보와 동일하게 표시하지 않는다.
- 실제 타격 시점과 추정 타격 시점을 구분한다. 공개하지 않은 길이·기술·부위가 UI나 로그로 유출되지 않게 한다.
- 카드 효과로 허용된 필드만 플레이어 관찰 상태에 복사한다. UI는 상대 전체 계획을 직접 읽지 않는다.
- 공개 대상이 없는 경우 정보를 만들어내지 않는다.
- 여러 정보 카드의 중복 공개, 총 공개 상한, 성장에 따른 확대는 밸런스 항목이다. 전체 공개를 기본 효과로 만들지 않는다.

## 정보 카드 콘텐츠 초안

| 카드 | 발동/대상 | 공개 내용 | 정밀도 |
|---|---|---|---|
| 초반 간파 | 현재 콤보의 첫 동작 | 정확한 동작 카드. 페이크도 식별 | 확정 |
| 강타 감지 | 강공격처럼 보이는 준비 | 예상 타격 시점, 기술명은 숨김 | 추정, 페이크 가능 |
| 수비 분석 | 현재 콤보의 가드 | 가드 배치 구간 | 확정, 기술/보호 부위는 별도 공개 시만 표시 |
| 패턴 독해 | 이전 콤보와 같은 위치에 반복된 동작 | 조건을 만족하는 동작 | 확정 |
| 카운터 본능 | 직전 콤보에서 회피 성공 | 다음 콤보 공격 일부 | 확정, 공개량 미정 |

기존 활성 Skill Card 한도 안에서 다른 스타일 카드와 경쟁한다.
해금과 성장은 선수의 훈련·경기 이력에서 발생한다.
Fight IQ, 영상 분석, 패턴 학습은 관찰과 해석에 연결하되 정확한 공개량 공식은 아직 확정하지 않는다.
NPC 정보 카드의 현재 턴 공개 방식은 상대 선확정 구조와 충돌하지 않도록 별도 설계한다. 플레이어 확정 후 NPC 재계획으로 해결하지 않는다.

## 우선 시제품과 연출

복싱 중심 시제품에서 배운 기술 자유 배치, 스태미너, 가드/회피 상성, 페이크, 카운터와 정보 공개를 검증한다.
무작위 드로우는 초기 시제품에 넣지 않는다. 다른 Ruleset은 전체 게임 범위에 유지하고 이후 확장한다.
전투 엔진이 결과 이벤트를 계산하고 측면 캐릭터 연출이 이를 재생한다.
애니메이션 재생 속도나 스킵 여부가 판정에 영향을 주면 안 된다.
실시간 3D 대전 프로젝트 통합은 현재 필수 개발 경로에서 제거한다.

## 구현 전 결정할 세부 규칙

- 같은 시점 타격의 동시 판정, 피격 경직과 남은 행동 취소.
- 콤보 경계에서 회수/카운터 기회 이월 여부.
- 빈칸의 동작, 중간 삽입/중복 사용, 범위를 넘는 배치 처리.
- 스태미너 부족 시 행동 실패와 후속 행동 처리.
- 속도 스탯의 타격 시점 반영, 거리 변화 및 회피 궤도 상성.
- 카드별 공개량, 선택 우선순위, 중첩 상한과 성장 효과.
- 라운드 종료, 판정승, 피니시 시 남은 타임라인 처리.

위 항목은 임의 확정 수치를 넣지 않고 시제품 규칙을 작성할 때 명시한다.

## 검증 기준

- 동일 초기 상태·계획·설정·Seed로 동일 결과 재현.
- 정보 생성 전후 상대 계획이 동일하며 플레이어 배치 변경이 상대 계획을 바꾸지 않음.
- 확정 공개가 원래 계획과 일치하고 페이크를 진짜 공격이라고 거짓 확정하지 않음.
- 추정 예고는 페이크에 속할 수 있으나 실제 결과와 구분되어 기록됨.
- 공개되지 않은 필드가 플레이어 화면/플레이어용 로그에 나타나지 않음.
- 패턴 독해는 반복 조건에서만 발동하고 카운터 본능은 회피 성공 이후에만 발동.
- 카드 없이도 과거 패턴을 관찰하고 예측 가능.
- 순서 변경이 방어·카운터·자원 교환에 영향을 주며 가드 반복이 무조건 우월하지 않음.
- 애니메이션을 스킵해도 결과가 동일함.
