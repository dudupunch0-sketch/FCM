# 입체 복서 모델과 애니메이션 업그레이드

## 범위

카드 UI와 전투 판정은 유지하고 캐릭터 표현과 재생 연출을 개선한다.
실시간 물리 대전으로 전환하지 않는다. 기존 판정 이벤트를 입체 렌더러가 재생한다.

## 모델과 재질

- Three.js 기반 입체 메시: 가슴·어깨·복부·팔다리, 턱·코·귀·눈·머리카락, 글러브·손목 랩·쇼츠·복싱화.
- 피부, 무광 천, 가죽 글러브의 재질을 구분한다.
- 키 라이트, 측후면 조명, 링 바닥 그림자로 실루엣과 부피를 표현한다.
- 모델은 코드로 생성한 스타일화된 원본 메시다. 실사 스캔이나 외부 상용 캐릭터 자산은 아니다.

## 움직임

- 앞손 잽과 뒷손 크로스 구분, 체중 이동·골반 회전·뒷발 피벗.
- 준비 → 빠른 타격 → 회수의 비대칭 곡선.
- 상단/바디 가드, 스웨이, 동작 전체에 걸친 연속 위빙, 페이크, 호흡.
- 팔·다리의 두 관절 IK로 길이를 보존하며 손과 발의 목표 위치를 추적한다.
- 머리와 몸통 피격 반응, 다운 자세, 강타/카운터의 짧은 화면 정지와 충격 입자.
- 모션의 동작 내부 경계는 연속적으로 연결한다. 서로 다른 카드 사이의 고급 블렌딩이나 모션 캡처는 아직 포함하지 않는다.

## 파일

- `dist/fighter-model.js`: 메시·재질과 관절 IK.
- `dist/motion.js`: 렌더러에 독립적인 동작 곡선과 재생 시계의 타격 정지.
- `dist/ring-3d.js`: 링·조명·카메라·입체 캐릭터와 효과.
- `dist/ring.js`: 입체 렌더러 초기화와 기본 Canvas 전환.
- `dist/ring-legacy.js`: WebGL 초기화가 불가능한 환경의 기본 화면.

Three.js는 버전을 고정해 `dist/vendor`에 포함한다. 실행 시 CDN 접속이나 패키지 설치는 필요 없다. 라이선스는 해당 디렉터리의 `THREE-LICENSE.txt`에 보존한다.

## 검증과 한계

기존 전투 테스트에 모션 경계 연속성, 앞손/뒷손 구분, IK 길이, 모든 동작의 유한 좌표와 모델 범위, 타격 정지의 단발성 및 판정 불변성 검증을 추가한다.
브라우저/실기기에서의 화면·성능 검증은 별도로 실시해야 한다. 특히 모바일 GPU의 부하와 실제 접촉감은 플레이 피드백을 통해 조정한다.
기본 렌더러 전환은 WebGL 생성 실패에 대응한다. 사용 중 컨텍스트 손실 시에는 브라우저 복원을 기다린다.

참고: [Three.js WebGLRenderer](https://threejs.org/docs/pages/WebGLRenderer.html), [그림자 가이드](https://threejs.org/manual/en/shadows.html).
