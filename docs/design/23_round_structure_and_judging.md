# FCM Delegated Design 23 — 라운드 구조와 판정 집계

> 상태: 사용자 승인 방향 반영. 턴 수와 회복량 등 수치는 미확정이며 Config로 관리한다.
> 기준: [현재 결정](../spec/current_decisions.md), [콤보형 턴제 전투](18_combo_turn_combat_and_information_cards.md)
> 범위: 콤보 턴과 경기 라운드의 연결, 경계 처리, 판정 집계. 구현 완료를 의미하지 않는다.

## 해결하는 문제

데이터 모델에는 `FightDefinition.rounds`, `round_duration`, `FightState.judge_cards[]`가 이미 존재하지만
전투 모델에는 라운드가 없었다. `18번`은 "라운드 시간에 콤보를 어떻게 대응시킬지"를 미결로 남겼고
시제품은 "최대 12교환 후 간단 판정"이라는 임시 규칙으로 우회했다.

판정승 집계, 인터벌 회복, 코너 지시 타이밍, 라운드 종료 시 남은 타임라인 처리가 모두 여기에 걸려 있다.

---

# 1. 확정 방향

**한 라운드는 고정된 개수의 콤보 턴으로 구성한다.**

```text
경기 = R개 라운드 × 라운드당 T개 콤보 턴
콤보 턴 = 8칸
```

**시간은 판정에 사용하지 않는다.**
1칸에 대응하는 초 단위 환산값을 두되 연출과 UI 표기 전용이며 판정 로직이 이를 읽지 않는다.
시간 기반 로직을 나중에 끼워 넣지 않는다.

## 이 선택의 핵심 이득

콤보 턴이 라운드 경계에서 **절대 잘리지 않는다.**
따라서 `18번`의 미결 항목인 "라운드 종료 시 남은 타임라인 처리"가 규칙 없이 해소된다.
모든 턴은 항상 8칸을 온전히 소비하거나, 피니시로 즉시 종료된다. 제3의 경우가 없다.

## 턴 수

`R`과 `T`는 Ruleset과 Part별 Config다. 아래는 초기 후보이며 확정값이 아니다.

| 맥락 | R | T | 비고 |
|---|---|---|---|
| Part 1 Underground | 3 | 5 | 짧은 경기. 클럽 규정은 느슨함 |
| Part 2 Boxing | 3~5 | 6 | 타이틀전은 라운드 수 증가 |
| Part 2 MMA | 3 | 8 | 라운드 시간이 길어 턴 수가 많음 |
| No Rules | 미정 | 미정 | 라운드 구분 자체가 없을 수 있음 |

MMA의 턴 수가 많은 이유는 라운드 실시간이 길기 때문이며, 이는 시간 환산 표기와의 일관성을 위한 것이다.
판정은 여전히 턴 수로만 이루어진다.

---

# 2. 라운드 경계 처리

경계에서 무엇이 이월되고 무엇이 사라지는지를 명시한다.
명시하지 않으면 구현마다 달라지고 재현성이 깨진다.

| 항목 | 라운드 경계 | 근거 |
|---|---|---|
| 부위별 손상 | **이월** | 전신 HP가 없고 손상 누적이 피니시 조건이다 |
| Permanent Wear | **이월** | 경기 후까지 남는 계층이다 |
| 스태미너 | **부분 회복** | 인터벌 회복. 아래 3장 |
| 거리 `gap` | **리셋** | 라운드는 항상 중립 거리에서 시작한다 |
| 카운터 기회 | **소멸** | 회피 보상은 짧은 기회이며 영구 보관하지 않는다 |
| 페이크 빈틈 | **소멸** | 같은 원칙 |
| 피격 경직 | **소멸** | 턴 내부 상태다 |
| Combat Memory / 패턴 노출 | **이월** | 학습은 경기 전체에 걸쳐 누적된다 |
| Read Confidence | **이월** | 같은 원칙 |
| 다운 횟수 | **양쪽 추적** | 라운드별 카운트와 경기 누적을 모두 기록한다 |
| 활성 Skill Card | **유지** | 경기 단위로 선택한다 |

## 정보 카드의 "직전 콤보" 조건

패턴 독해와 카운터 본능은 직전 콤보를 조건으로 삼는다.
**라운드 첫 턴에서는 직전 라운드의 마지막 턴을 직전 콤보로 취급한다.**
Combat Memory가 이월되므로 정보 조건도 이월하는 것이 일관적이다.
라운드마다 관찰이 초기화되면 라운드 첫 턴에서 정보 카드가 무력해진다.

---

# 3. 인터벌 회복

라운드 사이 스태미너 회복은 고정값이 아니다.

영향 요소:
- Cardio
- 누적 Damage, 특히 Body
- Recovery Debt / Fight Readiness
- Weight Stress
- 코너 Staff 품질

카디오가 좋은 선수는 라운드를 거듭해도 회복하고, 나쁜 선수는 회복 폭이 점점 줄어든다.
이는 후반 라운드 붕괴를 확률이 아닌 **인과로** 만든다. Randomness 철학과 일치한다.

회복 공식과 상한은 Config로 둔다.
완전 회복은 허용하지 않는다.

---

# 4. 코너 지시

**라운드 사이가 플레이어의 정규 개입 창이다.**

가능한 행동 후보:
- Strategy 조정
- 다음 라운드 방침 지시
- 관찰된 상대 패턴 확인
- 부상·상태 보고 확인

코너 지시의 반영 정도는 Fighter의 **Tactical Execution**에, 지시 품질은 **Player Coaching과 Staff**에 의존한다.
좋은 지시를 해도 Tactical Execution이 낮으면 그대로 수행되지 않는다.

상세 규칙은 Combat Intelligence 명세(로드맵 Phase 3)에서 확장한다.

---

# 5. 판정 집계

기존 Universal Judging Core를 유지한다. Ruleset별 불가능 Category만 비활성화한다.

집계는 2단이다.

```text
턴별 Judge Metric 누적
  → 라운드 단위 집계 → 라운드 결과
  → 라운드 결과 합산 → 경기 판정
```

라운드 결과는 승패뿐 아니라 **격차**를 내부적으로 보유한다.
근소하게 이긴 라운드와 압도한 라운드가 같은 값이 되면 판정 논란과 Rivalry 생성(`current_decisions:29장`)의 재료가 사라진다.

UI 표기 형식은 Ruleset별 관례를 따른다. 내부 집계 구조는 하나다.
`JudgingProfile`의 가중치가 그대로 라운드 집계에 사용된다.

---

# 6. 피니시와 턴 종료

| 상황 | 처리 |
|---|---|
| KO / TKO | 해당 턴의 남은 칸을 즉시 종료하고 경기 종료 |
| 다운 | 해당 턴의 남은 칸을 종료하고 카운트를 턴 경계 이벤트로 처리 |
| 라운드 마지막 턴 | 항상 8칸 완주. 잘림 없음 |
| 최종 라운드 종료 | 판정으로 이행 |

다운 이후 회복 상태로 재개할지, 라운드를 조기 종료할지는 미결이며 Ruleset Config 후보다.

---

# 7. 기존 시스템과의 연결

| 시스템 | 연결 |
|---|---|
| Cardio | 인터벌 회복 폭을 통해 후반 라운드 성능을 결정 |
| Damage / Finish | 손상 이월이 라운드를 넘어 피니시 조건을 형성 |
| Combat Memory | 이월되어 경기 후반의 읽기 정확도를 높임 |
| Tactical Execution | 코너 지시 반영률 |
| Judging | 라운드 단위 집계와 격차 보존 |
| Ticket Power | 라운드별 전개가 명경기 판정의 입력이 됨 |

---

# 8. 미결 항목

- Ruleset / Part별 `R`, `T` 확정값
- 인터벌 회복 공식과 상한
- 다운 이후 처리와 라운드 조기 종료 여부
- 10점 must 등 Ruleset별 표기 관례 채택 범위
- No Rules의 라운드 구조. 라운드 없는 단일 흐름 가능성
- 라운드 수가 다른 경기 간 Cardio 요구의 밸런스

---

# 9. 검증 기준

- 콤보 턴이 라운드 경계에서 잘리는 경우가 존재하지 않는다
- 동일 Seed·계획·설정에서 라운드 전개와 판정이 동일하게 재현된다
- Cardio가 낮은 선수가 후반 라운드에 실제로 붕괴하며 그 원인이 로그에서 추적된다
- 라운드 경계에서 카운터 기회와 페이크 빈틈이 소멸하고 Combat Memory는 유지된다
- 라운드 첫 턴에서도 패턴 독해와 카운터 본능이 직전 라운드 기준으로 발동한다
- 근소한 라운드와 압도한 라운드가 내부 집계에서 구분된다
- 판정 결과가 라운드별 집계의 합과 일치하며 별도 보정이 개입하지 않는다
