# 모바일 도트 전투와 콤보 편집

## 이번 변경

- 세로 모바일 화면에 선수 상태, 전투 장면, 상대 정보, 내 콤보, 동작카드, 실행을 함께 배치한다.
- 계획에는 제한 시간이 없다. 실행 중에는 양측 콤보를 빠르게 재생하고 동작 편집을 잠근다.
- 기본 재생 속도는 기존 기준의 두 배다. 강타와 카운터의 짧은 정지는 유지한다.
- 실행이 끝나면 별도의 결과 확인 버튼 없이 다음 계획으로 돌아간다. 직전 배치를 유지하고 상대 계획은 새로 확정한다.
- 배치된 동작을 선택하면 다른 카드로 교체, 삭제, 앞으로/뒤로 이동할 수 있다. 되돌리기는 직전 편집 상태를 복원한다.
- 동작카드는 공격·수비·전술로 묶는다. 전체 기술은 유지하며 카드 설명에서 자세한 규칙을 읽는다.
- 상세 로그, 지난 상대 콤보, 상대·정보 스킬 설정, 예시 콤보, 속도, 소리, 다시 보기는 메뉴로 이동한다.
- 메뉴를 열거나 앱이 배경으로 가면 전투를 일시정지한다. 일시정지는 관찰용이며 확정된 동작을 바꾸지 못한다.
- 다시 보기와 건너뛰기는 경기 결과에 영향을 주지 않는다. 다음 상대의 숨겨진 계획은 재생 후 공개하지 않는다.
- 예상 스태미너는 내 동작 순서와 호흡만 계산하며 피격·블록 소모는 제외했다고 표시한다.

## 화면과 접근성

일반적인 세로 화면에서 핵심 조작을 함께 배치하며, 화면 높이가 매우 작거나 글자를 확대하면 문서 스크롤로 접근성을 유지한다. 모든 기기에서 무조건 스크롤을 금지하지 않는다. 실기기 및 브라우저 레이아웃 QA는 아직 수행하지 않았다.

## 도트 선수

기존 WebGL 렌더 대신 Canvas의 투명 스프라이트 아틀라스를 사용한다. 상대 선수는 흑발 복서, 플레이어는 기존 링크 레퍼런스의 날렵한 실루엣·금발 헤어 덩어리·또렷한 눈·좁아지는 턱선을 반영한 복서 시안이다. 이 외형을 사용자의 최종 승인된 캐릭터로 간주하지 않는다.

생성 이미지의 배경은 알파로 투명하며, 발 위치를 동작마다 보정한 소스 사각형과 기준점으로 렌더한다. 대기·펀치·가드·스웨이·위빙·페이크·피격·호흡·다운 자세와 짧은 이동/타격 효과를 연결했다. 잽과 크로스의 플레이어 자세는 손과 몸통 방향이 다르다. 훅과 강타는 준비 자세와 공통 타격 자세를 연결하는 초기 모션이며 전용 연속 프레임은 후속 개선 대상이다.

파일:
- `dist/assets/player-pixel-sheet.png`: 플레이어 아틀라스
- `dist/assets/boxer-pixel-sheet.png`: 상대 아틀라스
- `dist/pixel-motion.js`: 소스 사각형, 발 기준점, 동작별 프레임 선택
- `dist/ring-pixel.js`: 표시 전용 렌더러
- `dist/planner.js`: 편집과 상대 정보 없는 스태미너 예상

이미지 생성은 내장 imagegen을 사용했다. 플레이어 생성 시 `docs/art/reference/link/README.md`를 읽고 `totk-link-official.webp`, `botw-link-key-art.jpg`를 직접 열고 입력으로 첨부했다. 참조 파일은 GitHub main `a182c6f425b1351b1af0ae63ba92f58cfdc31007`에서 확인한 기준과 대응한다. 닌텐도 원본은 개발 자료이며 실행 배포에 넣지 않는다.

생성 브리프: 투명 배경의 균일한 도트 복싱 동작 시트. 플레이어는 링크 참고 이미지의 슬림한 성인 실루엣, 금발 묶은 머리, 푸른 눈, 좁은 턱선을 복싱 반바지·글러브·부츠로 변환. 상대는 흑발과 단단한 체형의 성인 복서. 각 시트는 동일 인물의 대기, 잽, 크로스, 훅, 상단 가드, 바디 가드, 스웨이, 위빙, 피격, 호흡, 페이크, 다운 순서. 글자·격자·배경 없이 발 위치와 크기를 유지한다.

## 검증

기존 전투·모션 테스트와 새 편집·스태미너·아틀라스 범위 테스트를 수행했다. DOM 대역을 사용하는 컨트롤러 테스트로 자동 다음 계획, 배치 유지, 숨겨진 정보 제한, 일시정지, 다시 보기, 교체와 되돌리기를 확인했다. 실제 아틀라스를 Canvas로 렌더하여 투명 배경과 발 위치를 확인했다. 이것은 브라우저나 실제 휴대폰에서의 화면/성능 검증을 대신하지 않는다.
