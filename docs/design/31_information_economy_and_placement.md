# FCM Delegated Design 31 — 정보 공개 경제와 배치 규칙

> 상태: 수치는 초기 후보이며 밸런싱 전이다.
> 기준: [콤보형 턴제 전투](18_combo_turn_combat_and_information_cards.md), [선수 계획 생성](28_fighter_plan_generation.md)
> 실물 Config: `config/information_cards.json`
> 범위: `18번`이 남긴 마지막 미결 두 건과 Skill Card 이중 역할 리스크의 해소.

## 해결하는 문제

`18번`은 "정보 카드가 필수 장착이 되지 않도록 검증한다"라고 썼지만 검증 기준을 두지 않았다.
정보 카드와 스타일 카드가 **같은 활성 5장 한도를 공유**하는데, 정보 카드가 항상 우월하면
Liver Hunter나 Chain Wrestler 같은 스타일 카드 콘텐츠가 통째로 죽는다.

카드별 공개량, 중첩 상한, 성장 효과, 그리고 빈칸·중복 배치 규칙도 모두 미정이었다.

---

# 1. 이중 역할 — 한도를 분리하지 않는다

가장 먼저 떠오르는 해법은 정보 카드 전용 슬롯을 따로 만드는 것이다.
**이 해법을 채택하지 않는다.**

전용 슬롯을 만들면 슬롯이 항상 비어 있으므로 항상 무언가를 끼우게 된다.
즉 **정보 카드가 구조적으로 필수가 된다.** `18번`이 막으려던 바로 그 상태를 설계로 보장하는 셈이다.

대신 같은 5장 한도 안에서 경쟁시키고, **무카드 기준선을 실제로 쓸 만하게 유지한다.**

## 정보 카드가 파는 것은 정보가 아니라 확실성이다

`18번`은 이미 "정보 카드가 없어도 이전 콤보와 관찰한 반복 습관을 확인할 수 있다"라고 확정했다.
이 기준선이 실제로 작동하면 정보 카드의 가치는 "볼 수 있다 / 없다"가 아니라
**"추측한다 / 확정한다"** 로 바뀐다.

그 순간 정보 카드는 스타일 카드와 같은 층위의 선택지가 된다.
확실성을 살 것인가, 공격 특성을 살 것인가.

따라서 무카드 기준선은 밸런스 항목이 아니라 **이 시스템이 성립하기 위한 전제**다.
Config에서 끌 수 있게 두지 않는다.

---

# 2. 공개 예산

카드별 공개량을 따로 정하지 않고 **턴당 총 공개 예산**을 둔다.

- 장착한 모든 정보 카드가 **하나의 예산을 나눠 쓴다**
- 확정(Exact) 공개는 비싸고, 추정(Cue) 예고는 싸다
- 예산과 확정 공개 개수 모두 상한이 있다

## 중첩의 수익은 체감한다

정보 카드를 여러 장 끼워도 예산이 늘지 않는다.
두 번째, 세 번째 카드는 **더 많은 정보가 아니라 더 넓은 발동 조건**을 산다.

`18번`의 "여러 정보 카드의 중복 공개, 총 공개 상한... 전체 공개를 기본 효과로 만들지 않는다"가 이 구조로 구현된다.

**최대 예산에서도 8칸 계획 전체를 볼 수 없다.** 부분적 지식은 튜닝 실수가 아니라 구조다.

## 성장은 예산을 올리지 않는다

카드 레벨은 정밀도를 높이고 발동 조건을 완화한다. **예산 상한은 건드리지 않는다.**
성장으로 전체 공개에 수렴하는 경로를 원천적으로 막는다.

## 우선순위는 결정론적이다

여러 카드가 같은 예산을 두고 경쟁하면 발동 조건 구체성 → 카드 레벨 → 카드 ID 순으로 해소한다.
같은 배치를 두 카드가 공개하면 예산은 한 번만 쓴다.

재현성을 위해 필요하다. 임의 순서를 허용하면 같은 Seed에서 다른 정보가 나온다.

---

# 3. NPC와의 비대칭

28번에서 확정한 대로 NPC의 정보 카드는 회고적으로만 작동한다.
따라서 **NPC는 이 예산 체계를 쓰지 않는다.**

정보 카드를 가진 NPC는 예측 신뢰도와 기억 창이 늘어난 상대로 나타난다.
이 비대칭은 확정 순서에서 나오는 구조적 결과이며 28번 4장에 근거가 있다.

---

# 4. 배치 규칙

시제품의 임시 규칙을 명세로 승격한다.

| 항목 | 규칙 |
|---|---|
| 빈칸 | 호흡 정리로 처리 |
| 동일 동작 반복 | 허용 |
| 범위 초과 배치 | 거부 |
| 중간 삽입 | 뒤 동작을 밀어냄. 8칸을 넘기면 삽입 거부 |

## 반복을 금지하지 않는 이유

같은 동작의 반복은 **패턴 노출을 키운다.** 노출이 커지면 상대의 Read Confidence가 올라가고
26번의 방어 타이밍 보정이 작동한다.

즉 반복은 규칙으로 막을 필요가 없다. **이미 게임이 처벌한다.**
금지 규칙을 추가하면 플레이어가 왜 안 되는지 모르는 벽이 하나 더 생길 뿐이다.

## 넘치는 배치를 잘라내지 않는 이유

8칸을 넘기는 삽입은 조용히 뒷부분을 잘라내지 않고 거부한다.
플레이어가 확정한 계획과 실제 실행 계획이 달라지면 안 된다.
이는 `18번`의 "확정 정보는 실제 잠긴 계획과 일치한다"와 같은 원칙이다.

---

# 5. 미결 항목

- `per_turn_total` 3과 Exact 비용 2의 타당성
- 카드 5종의 개별 발동 조건 구체화. 현재는 콘텐츠 초안 수준
- 스타일 카드와의 실제 경쟁력 비교. 플레이 후 조정
- 무카드 기준선의 history 창 6턴이 충분한지
- 정보 카드 해금 조건과 훈련·경기 이력의 연결
- 예산을 라운드 단위로도 제한할지

---

# 6. 검증 기준

- 정보 카드를 한 장도 끼우지 않아도 과거 콤보와 반복 습관을 볼 수 있다
- 정보 카드 없이 플레이한 경기가 승산 있게 진행된다
- 정보 카드를 여러 장 끼워도 턴당 총 공개량이 상한을 넘지 않는다
- 최대 예산에서도 상대 8칸 계획 전체가 공개되지 않는다
- 카드 레벨이 올라도 공개 예산이 늘지 않는다
- 두 카드가 같은 배치를 공개할 때 예산이 한 번만 소모된다
- 같은 Seed와 같은 카드 구성에서 공개 내용이 완전히 동일하다
- 정보 카드 전용 슬롯이 존재하지 않는다
- 같은 동작을 반복 배치하면 패턴 노출이 실제로 증가한다
- 8칸을 넘기는 삽입이 거부되며 조용히 잘려나가지 않는다
