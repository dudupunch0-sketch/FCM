# FCM Delegated Design 31 — 정보 공개 경제와 배치 규칙

> 상태: 수치는 초기 후보이며 밸런싱 전이다.
> 기준: [콤보형 턴제 전투](18_combo_turn_combat_and_information_cards.md), [선수 계획 생성](28_fighter_plan_generation.md)
> 실물 Config: `config/information_cards.json`
> 범위: `18번`이 남긴 마지막 미결 두 건과 Skill Card 이중 역할 리스크의 해소.

## 해결하는 문제

`18번`은 "정보 카드가 필수 장착이 되지 않도록 검증한다"라고 썼지만 검증 기준을 두지 않았다.
당시 구조에서는 정보 카드와 스타일 카드가 **같은 활성 5장 한도를 공유**했고,
정보 카드가 항상 우월하면 Liver Hunter나 Chain Wrestler 같은 스타일 카드 콘텐츠가 통째로 죽는다.

카드별 공개량, 중첩 상한, 성장 효과, 그리고 빈칸·중복 배치 규칙도 모두 미정이었다.

---

# 1. 이중 역할 — 한도를 분리한다

## 용어 정리

정보 카드는 별개의 카드 종류가 아니다. **Skill Card의 한 갈래**다.

| | 무엇 | 어디에 |
|---|---|---|
| Action Card | 배운 Technique을 쓰는 조작 단위 | 매 턴 8칸 타임라인에 배치 |
| **Skill Card** | 선수 특성. 경기 전 활성화 | 배치하지 않음. 조건 충족 시 작동 |

Skill Card 안에 정보 공개형(초반 간파, 패턴 독해, 카운터 본능)과
스타일형(Liver Hunter, Chain Wrestler)이 함께 있다. 같은 종류이기 때문에 한도를 공유했고, 그래서 문제가 생겼다.

**정보 공개형도 선수의 특성이다.** "패턴 독해"는 플레이어의 외부 도구가 아니라
그 선수가 상대를 읽어내는 눈이다. 이 점이 아래 3장의 Fight IQ 연동을 자연스럽게 만든다.

## 채택: 한도를 나눈다

| 갈래 | 활성 한도 |
|---|---|
| 스타일형 | 5장 (기존 유지) |
| 정보 공개형 | 1장 |

정보 공개형 1장은 시제품이 이미 하고 있는 방식(`19번`)이며, 이로써 시제품과 명세가 일치한다.

## 이 선택이 받아들이는 것과 얻는 것

분리는 **정보 카드가 사실상 항상 장착된다는 것을 받아들인다.**
`18번`의 "필수 장착이 되지 않도록"을 문자 그대로 만족시키지는 않는다.

대신 얻는 것이 크다.

- 플레이어의 결정이 **"확실성이냐 위력이냐"에서 "어떤 눈을 가져갈 것이냐"로 바뀐다.**
  앞의 것은 성질이 달라 비교가 안 되고, 뒤의 것은 비교 가능한 선택이다
- **양쪽 콘텐츠가 모두 실제로 쓰인다.** 공유 한도에서 정보 쪽이 이기면
  스타일 카드는 플레이 데이터가 아예 쌓이지 않아 밸런싱할 근거조차 생기지 않는다

## 되돌리는 조건

오버밸런스면 다시 단일 한도로 통합한다. 판단을 감에 맡기지 않도록 조건을 명시한다.

- 정보 카드가 계획을 시시하게 만들어 상대 읽기가 불필요해진다
- 정보 카드 하나가 나머지를 압도해 선택이 실질적으로 없다
- 전용 한도를 줬는데도 스타일 카드가 여전히 안 쓰인다

통합은 플레이어가 쓰던 것을 빼앗는 방향이라 분리보다 되돌리기가 껄끄럽다.
출시 전에는 실질 비용이 거의 없지만, 판단을 오래 미룰 항목은 아니다.

# 2. 공개 예산

카드별 공개량을 따로 정하지 않고 **턴당 총 공개 예산**을 둔다.

- 장착한 모든 정보 카드가 **하나의 예산을 나눠 쓴다**
- 확정(Exact) 공개는 비싸고, 추정(Cue) 예고는 싸다
- 예산과 확정 공개 개수 모두 상한이 있다

## 한도를 나눴는데 예산이 여전히 필요한 이유

정보 한도가 1장이면 중첩 문제는 당장 사라진다. 그래도 예산은 남긴다.

- **카드 하나가 8칸을 다 공개하는 것을 막는다.** 한도와 무관한 별개의 상한이다
- 성장의 상한선 역할을 한다(아래)
- 나중에 정보 한도를 2장으로 올릴 때 중첩 규칙을 새로 만들 필요가 없다

`18번`의 "총 공개 상한... 전체 공개를 기본 효과로 만들지 않는다"는 한도가 아니라 이 예산이 보장한다.

**최대 예산에서도 8칸 계획 전체를 볼 수 없다.** 부분적 지식은 튜닝 실수가 아니라 구조다.

## 성장은 예산을 올리지 않는다

카드 레벨은 정밀도를 높이고 발동 조건을 완화한다. **예산 상한은 건드리지 않는다.**
성장으로 전체 공개에 수렴하는 경로를 원천적으로 막는다.

## 우선순위는 결정론적이다

여러 카드가 같은 예산을 두고 경쟁하면 발동 조건 구체성 → 카드 레벨 → 카드 ID 순으로 해소한다.
같은 배치를 두 카드가 공개하면 예산은 한 번만 쓴다.

재현성을 위해 필요하다. 임의 순서를 허용하면 같은 Seed에서 다른 정보가 나온다.

# 3. 무카드 기준선과 Fight IQ

한도를 나눠도 무카드 기준선은 없앨 수 없다.

- 정보 카드를 아직 하나도 해금하지 못한 선수가 플레이 가능해야 한다
- 정보 카드의 가치를 **무엇과 비교해 재는지**의 기준선이 필요하다

기준선은 무료로 제공한다. 관찰된 과거 콤보, 반복 습관 표시, 페이크 이력.

## 기준선의 품질은 Fight IQ에 따라 달라진다

정보 공개형 카드가 **선수의 특성**이라는 점에서 따라 나오는 규칙이다.
상대를 읽는 것이 능력이라면, 원래 눈이 좋은 선수는 그 능력이 이미 있다.

- Fight IQ가 높으면 기준선의 관찰 창이 넓고 습관 표시가 정확하다
- Fight IQ가 낮으면 기준선이 좁고 흐려서 카드로 메꿔야 한다

28번이 이미 Fight IQ로 예측 신뢰도와 기억 창을 결정하므로, 새 축을 만들지 않고 같은 값을 쓴다.

**이것이 밸런스 장치가 아니라 설정상 당연한 결과라는 점이 중요하다.**
영리한 선수는 카드 한 장의 이득이 작고, 둔한 선수는 그 카드가 절실하다.
같은 카드가 선수마다 다른 가치를 갖게 되어, 한도를 나눈 뒤에도 선택이 남는다.

---

# 4. NPC와의 비대칭

28번에서 확정한 대로 NPC의 정보 카드는 회고적으로만 작동한다.
따라서 **NPC는 이 예산 체계를 쓰지 않는다.**

정보 카드를 가진 NPC는 예측 신뢰도와 기억 창이 늘어난 상대로 나타난다.
이 비대칭은 확정 순서에서 나오는 구조적 결과이며 28번 4장에 근거가 있다.

# 5. 배치 규칙

시제품의 임시 규칙을 명세로 승격한다.

| 항목 | 규칙 |
|---|---|
| 빈칸 | 호흡 정리로 처리 |
| 동일 동작 반복 | 허용 |
| 범위 초과 배치 | 거부 |
| 중간 삽입 | 뒤 동작을 밀어냄. 8칸을 넘기면 삽입 거부 |

## 반복을 금지하지 않는 이유

같은 동작의 반복은 **패턴 노출을 키운다.** 노출이 커지면 상대의 Read Confidence가 올라가고
26번의 방어 타이밍 보정이 작동한다.

즉 반복은 규칙으로 막을 필요가 없다. **이미 게임이 처벌한다.**
금지 규칙을 추가하면 플레이어가 왜 안 되는지 모르는 벽이 하나 더 생길 뿐이다.

## 넘치는 배치를 잘라내지 않는 이유

8칸을 넘기는 삽입은 조용히 뒷부분을 잘라내지 않고 거부한다.
플레이어가 확정한 계획과 실제 실행 계획이 달라지면 안 된다.
이는 `18번`의 "확정 정보는 실제 잠긴 계획과 일치한다"와 같은 원칙이다.

# 6. 미결 항목

- `per_turn_total` 3과 Exact 비용 2의 타당성
- 정보 활성 한도 1장이 맞는지. 2장으로 올리면 선택 폭은 늘지만 중첩 문제가 돌아온다
- 카드 5종의 개별 발동 조건 구체화. 현재는 콘텐츠 초안 수준
- 1장 안에서 5종의 선택이 실제로 갈리는지. 하나가 압도하면 통합 조건에 해당한다
- Fight IQ에 따른 기준선 스케일 범위. 높은 쪽에서 카드가 무의미해지지 않아야 한다
- 정보 카드 해금 조건과 훈련·경기 이력의 연결
- 예산을 라운드 단위로도 제한할지

---

# 7. 검증 기준

- 정보 카드를 장착해도 스타일 카드 활성 한도가 줄지 않는다
- 정보 카드를 한 장도 끼우지 않아도 과거 콤보와 반복 습관을 볼 수 있다
- 정보 카드가 해금되지 않은 선수로도 경기를 진행할 수 있다
- 최대 예산에서도 상대 8칸 계획 전체가 공개되지 않는다
- 카드 레벨이 올라도 공개 예산이 늘지 않는다
- 두 카드가 같은 배치를 공개할 때 예산이 한 번만 소모된다
- 같은 Seed와 같은 카드 구성에서 공개 내용이 완전히 동일하다
- Fight IQ만 다른 두 선수가 같은 카드로 다른 기준선 품질을 갖는다
- Fight IQ가 최대여도 무카드 기준선이 카드 공개를 완전히 대체하지 않는다
- 같은 동작을 반복 배치하면 패턴 노출이 실제로 증가한다
- 8칸을 넘기는 삽입이 거부되며 조용히 잘려나가지 않는다
