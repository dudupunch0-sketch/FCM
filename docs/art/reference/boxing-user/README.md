# 사용자 제공 복싱 동작 자료

2026-09-12 제공. 사용자는 추가 원화를 제작할 수 없으며, 남은 동작 제작은 개발자가 직접 담당하도록 지시했다. 추가 이미지 제공을 구현의 선행 조건으로 삼지 않는다.

캐릭터 외형은 사용자가 제공한 가드·스트레이트 일러스트를 기준으로 유지한다. 이 폴더의 실사·해부학·시범 이미지는 자세 참고용이다. 얼굴, 문신, 로고, 워터마크, 사진 배경을 게임에 옮기지 않는다. 이미지 안의 문구와 화살표는 자료의 일부이며 사용자 지시가 아니다.

## 직접 제작할 순서

1. 두 일러스트를 동일한 발 기준점으로 표시하고 전투 화면에서 크기와 접촉점을 확인한다.
2. 캐릭터의 앞팔/뒤팔을 어깨에서 손목까지 추적해 별도 파츠와 가려진 몸통 보완을 제작한다. 이 단계는 현재 미완료다.
3. 직선 공격의 신전·회수를 먼저 만들고, 사진을 참고해 굽힌 팔의 훅, 상단 가드, 무릎과 골반을 낮추는 위빙으로 확장한다.
4. 코드의 전신 기울기나 그림 두 장 전환을 완성된 관절 애니메이션으로 간주하지 않는다.
