# FCM 기획 인터뷰 05 — Setup / Combat Memory / Coaching Analysis

> 프로젝트 가제: **Fight Club Manager (FCM)**  
> 목적: 전투 내 패턴 적응, Setup, 경기 전 비디오 분석, 코칭 개입, 경기 후 분석 리포트 구조 확정  
> 상태: **5차 인터뷰 확정안**

---

## 0. 이전 제안 승인

다음 방향은 승인한다.

- 숨겨진 Derived Capability는 존재 자체와 작동 원리를 플레이어가 알 수 있어야 한다.
- 정확한 내부 수치와 계산식은 숨기되, 툴팁/튜토리얼/관찰/분석 리포트 등을 통해 시스템의 존재는 명확히 전달한다.
- Setup은 선수 스탯이 아니라 전투 도중 형성되는 Context/History 기반 시스템으로 설계한다.
- 전투 결과는 승패 확률 롤이 아니라 행동 단위의 인과관계 누적으로 결정한다.
- Randomness는 결과의 작은 편차를 만들 수 있으나 사건의 근본 원인이 되어서는 안 된다.

---

## A. Combat Memory 범위

- 선수는 **현재 경기 전체의 패턴과 습관을 기억**한다.
- 오래된 패턴 정보는 시간이 지나면서 영향력이 감소할 수 있다.
- 상대의 습관은 경기 중 관찰만으로 파악되는 것이 아니라, 경기 전 활동으로도 획득할 수 있다.

### 상대 경기 비디오 분석

플레이어는 경기 전 활동으로 **상대 경기 비디오 분석**을 수행할 수 있다.

이를 통해 다음 정보를 얻을 수 있다.

- 자주 사용하는 콤보
- 특정 상황에서 반복하는 시퀀스
- 공격 후 이동 방향
- 방어 후 반격 습관
- 타격에서 그래플링으로 전환하는 패턴
- 특정 데미지를 받은 뒤 보이는 행동
- 라운드 후반의 반복 습관

이 정보는 플레이어가 라운드 전략을 설계할 때 사용한다.

### 정보의 정확도

분석 결과는 절대적인 사실이 아닐 수 있다.

다음 이유로 잘못된 정보를 얻을 수 있다.

- 오래된 경기 자료
- 최근 스타일 변화
- 의도적으로 기존 습관을 바꾼 상대
- 데이터 부족
- 분석자의 낮은 능력
- 상대가 과거 경기에서 의도적으로 보여준 패턴

잘못된 정보를 선수에게 전달하면 선수가 경기에서 오히려 고전할 수 있다.

따라서 경기 전 정보에도 **신뢰도/최신성/근거량** 등의 내부 수치가 필요하다.

---

## B. Pattern 단위

FCM의 Pattern 인식은 단순 행동 빈도보다 **콤보 및 시퀀스 중심**으로 설계한다.

예:

- Jab → Jab → Cross
- Jab → 우측 이동
- Body Straight → Low Kick
- Punch Combination → Takedown
- 상대 진입 → Back Step → Counter
- 특정 공격 실패 → Clinch

단일 기술 빈도 역시 참고할 수 있으나 핵심은 연속 행동의 관계를 학습하는 것이다.

---

## C. Fight IQ와 Pattern Adaptation

높은 Fight IQ는 다음에 긍정적으로 작용한다.

- 상대 패턴을 더 빠르게 파악
- 적은 Evidence로 유효한 Pattern을 발견
- 우연한 행동과 실제 습관을 구분
- 자신의 반복 패턴이 상대에게 읽히고 있음을 인지
- Pattern Break 타이밍 판단
- Feint와 Counter에 유리한 Setup 상황 판단
- 상대의 잘못된 예측을 역이용

즉 Fight IQ는 단순 전투 보너스가 아니라 **Combat Memory와 Setup 시스템의 핵심 해석 능력**으로 작동한다.

---

## D. Setup은 자동과 직접 지시 모두 가능

Setup은 두 가지 경로로 활용한다.

### 1. 선수 자율 Setup

Fight IQ가 높은 선수는 스스로 Pattern을 만들고 이를 역이용할 수 있다.

### 2. 플레이어 지시 Setup

플레이어는 경기 전 또는 라운드 작전 시간에 Setup 전략을 직접 지시할 수 있다.

예:

- Jab → Jab → Cross 패턴을 반복하여 상대 반응 유도
- Body 공격을 보여준 뒤 Head 공격
- Low Kick을 반복해 Check를 유도한 뒤 다른 공격 사용
- Punch를 보여준 뒤 Takedown

Setup에는 **성공/실패 판정**이 존재한다.

예:

> Jab-Jab-Cross 패턴 Setup 축적 성공

이와 같은 정보를 플레이어가 전투 중 또는 라운드 사이에 확인할 수 있다.

이후 플레이어는 해당 Setup을 실제로 활용하도록 선수에게 지시할 수 있다.

---

## E. Fight IQ와 Tactical Execution 역할 분리

플레이어가 Setup을 지시했을 때 두 능력치는 서로 다른 역할을 맡는다.

### Fight IQ

- Setup이 실제로 유효한 상황인지 판단
- 상대 반응을 읽음
- Setup을 활용할 적절한 타이밍 탐색
- 예상과 다른 상황에서 전략을 조정

### Tactical Execution

- 플레이어가 지정한 콤보/시퀀스를 얼마나 충실히 수행하는지
- Setup 축적 과정에서 지시를 유지하는 능력
- 라운드 전략을 얼마나 안정적으로 실행하는지

---

## F. 코너 개입과 코칭

라운드 사이 플레이어와 코치진은 선수에게 패턴 정보를 전달할 수 있다.

예:

- "상대는 잽 후 항상 오른쪽으로 빠진다."
- "네 로우킥을 의식하기 시작했다."
- "펀치 교환 뒤에 테이크다운이 들어온다."

이 개입은 선수의 Pattern Awareness를 증가시킬 수 있다.

따라서 선수가 스스로 파악하지 못한 패턴을 코치가 발견하여 전달하는 것이 가능하다.

전투 성능에는 선수 능력뿐 아니라 **플레이어와 코치진의 분석 능력**도 개입한다.

---

## G. 반복 패턴의 양면성

같은 행동 또는 시퀀스를 반복하는 것은 장점과 단점을 동시에 가진다.

### 장점

- 익숙한 기술의 안정적인 실행
- 선수의 강점을 지속적으로 활용
- Setup을 의도적으로 축적
- 상대에게 특정 Expectation을 형성

### 단점

- Pattern Exposure 증가
- 상대의 Read Confidence 증가
- Counter 또는 방어 성공 가능성 증가

따라서 플레이어는 다음 사이에서 판단해야 한다.

> 강점을 반복하여 압박할 것인가  
> vs  
> 상대에게 완전히 읽히기 전에 Pattern Break를 사용할 것인가

---

## H. Momentum / Flow State

- 별도의 Momentum 게이지 또는 Flow State 시스템은 **추가하지 않는다.**
- 경기 흐름에 따른 이점은 Setup, Combat Memory, Skill Card, Ring Name, 부위 데미지, Cardio 등 기존 시스템들의 상호작용으로 표현한다.
- 별도의 추상적인 마법 버프처럼 느껴지는 시스템은 지양한다.

---

## I. 경기 후 리포트

경기 후에는 서로 성격이 다른 **2종류의 리포트**를 제공한다.

### 1. 심판 점수 리포트

공식 경기 결과 관점의 객관적 리포트.

포함 가능 요소:

- 라운드별 점수
- 유효 타격
- 테이크다운
- 그라운드 컨트롤
- 공격성
- 경기 지배력
- 판정 근거

규칙별로 평가 기준은 다를 수 있다.

### 2. 코치진 분석 리포트

선수의 실제 경기 내용과 인과관계를 분석하는 내부 리포트.

예:

- 거리 싸움에서 지속적으로 열세
- 상대 Jab-Jab-Cross 패턴에 적응 실패
- Setup은 성공했으나 Pattern Break 타이밍을 놓침
- 후반 Cardio 감소로 Footwork 성능 하락
- 반복적인 Low Kick으로 왼쪽 다리 내구도 저하
- 상대의 Takedown Setup을 잘못 해석

이 리포트는 완전한 진실이 아닐 수 있다.

정확도와 상세도는 다음 요소의 영향을 받는다.

- 플레이어 캐릭터의 관련 능력
- 현재 고용한 코치진의 분석 능력
- 코치진 구성
- 경기 데이터의 양
- 경기 비디오 분석 여부
- 추가 분석 활동에 투입한 시간

---

## 코치진 성장 및 확장

게임이 진행되면서 플레이어는 추가 코치를 고용할 수 있다.

코치들은 서로 다른 분석 강점을 가질 수 있다.

예:

- Striking 분석
- Grappling 분석
- Pattern 분석
- Physical/Condition 분석
- 상대 전략 분석

복수의 코치진이 함께 경기 분석에 참여하며, 이들의 능력이 종합적으로 분석 리포트 품질에 영향을 준다.

---

## 경기 비디오 사후 분석

경기 종료 후 플레이어는 별도의 시간을 사용하여 **지난 경기 비디오 분석** 활동을 수행할 수 있다.

이를 통해 즉시 제공된 코치진 리포트보다 더 상세한 인과관계를 확인할 수 있다.

가능한 결과:

- 숨겨져 있던 패턴 발견
- 잘못 판단한 패턴 수정
- 선수 Base Parameter에 대한 Evidence 획득
- 상대 습관 데이터 갱신
- 전략 실패의 실제 원인 발견
- 향후 재대결에 사용할 정보 축적

따라서 경기 후 분석은 단순 기록 열람이 아니라 선수 성장, 스카우팅, 전략 개선으로 다시 연결되는 활동이다.

---

## 시스템 루프

FCM의 전투 분석 루프는 다음과 같이 정리한다.

**상대 경기 비디오 분석**  
→ 상대 습관/Pattern 정보 확보  
→ 정보 신뢰도 판단  
→ 경기 전 전략 및 Setup 설계  
→ 경기 중 Pattern Exposure/Expectation 형성  
→ 선수의 Fight IQ 기반 자율 판단  
→ 플레이어/코치의 라운드 사이 개입  
→ Setup 활용 또는 Pattern Break  
→ 경기 결과  
→ 심판 점수 리포트  
→ 코치진 인과관계 분석 리포트  
→ 필요 시 경기 비디오 사후 분석  
→ 선수 및 상대에 대한 Evidence 축적

---

## 확정 철학

> **경기 전에 얻은 정보도 완벽하지 않으며, 경기 중에는 상대와 나 모두 서로를 학습한다.**

> **좋은 Fight IQ는 숫자 보너스가 아니라 패턴을 더 잘 읽고, 더 잘 숨기고, 더 잘 이용하는 능력이다.**

> **플레이어의 코칭과 분석 능력 역시 선수의 경기력에 실제 영향을 준다.**

> **패배 원인을 설명할 수 있어야 하며, 분석에 시간과 인력을 투자할수록 더 정확한 원인을 알 수 있다.**
