## 이때 정해진 것 중 끝까지 살아남은 것

- **네 계층 구조**: Base Parameter → Derived Capability → Effective Performance → Action Result
- **높은 숫자의 총합이 정답이 되어서는 안 된다** — 이후 Base→Derived를 가중 기하평균으로
  구현하는 근거가 된다
- **True State와 Knowledge State의 분리** — 플레이어는 선수를 직접 보지 못한다
- **선수 능력치를 수정하지 않고 Action Data로 기술 밸런스를 조절한다**
- SSOT(`docs/spec/current_decisions.md`)를 두고 모든 결정을 여기로 모은다
