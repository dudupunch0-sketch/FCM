# 동작 검수 기록

2026-09-13. 렌더/자동 검사를 동작 품질 승인으로 대체하지 않는다.

- 첫 훅: 탈락. 접촉 팔꿈치가 거의 펴져 스트레이트처럼 보임.
- 첫 위빙: 탈락. 최저 자세에서 바로 기본 자세로 복귀함.
- 수정 훅: 독립 정지 프레임 검수 통과. 굽힌 팔꿈치와 몸통 회전, 동일 얼굴·헤어·복장 확인. 주먹이 카메라 쪽으로 단축되므로 실제 상대와 접촉 위치 검수 필요.
- 가드: 독립 정지 프레임 검수 통과. 기본·상승·닫힘·복귀의 양팔 연결 확인.
- 수정 위빙: 독립 정지 프레임 검수 통과. 6프레임의 낮추기·전진·중간 복귀 확인.
- 자동 추출/아틀라스: `ok: true`, 선언 프레임 수 4/4/6. 소재색과 투명 배경은 추출된 접촉 시트로 확인.
- 앱 내 브라우저에서 훅 75% 접촉 자세 확인: 주먹이 카메라 쪽으로 향해 상대 얼굴과 거리가 남음. 훅은 게임에서 비활성화하고 검수 화면에만 후보로 표시한다.
- 훅 3차 프롬프트는 준비됐지만 아직 생성하지 않았다. 현재 `raw/hook.png`는 2차 결과이며 최신 `prompts/hook.txt`와 일치하지 않는다. 다음 생성은 이 프롬프트부터 진행한다.
- 가드·위빙은 프레임 검수와 자동 QA 통과, 게임 연결 완료. 실제 정상 속도 재생·행 전환 크기·고정 발 검수는 미완료다.
